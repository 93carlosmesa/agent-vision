# Asset Licenses

## Sprite Assets

All sprite graphics in this project are **original procedural pixel art** generated at runtime via HTML Canvas (`public/sprites.js`). No external image files or third-party assets are used.

### License

All original sprites created for this project are released under **CC0 1.0 Universal (Public Domain Dedication)**.

You may copy, modify, distribute, and use them for any purpose, including commercial, without asking permission.

### Character Themes

| Theme | Characters | Description |
|-------|-----------|-------------|
| People | Dev, Wizard, Spy, Builder, Scientist, Astro, Hero, Artist | Simple humanoid pixel art with distinct color palettes |
| Creatures | Flamey, Aquari, Leafor, Sparky, Shado, Dusty, Crystal, Drako | Original elemental/monster designs — not based on any existing franchise |
| Animals | Gato, Perro, Buho, Zorro, Oso, Pinguino, Aguila, Delfin | Stylized animal pixel art |

### Important Notes

- **No copyrighted assets** are used anywhere in this project.
- The "Creatures" theme contains entirely original designs. They are not derivatives of Pokémon, Digimon, or any other franchise.
- All sprites are 16×16 pixel art rendered at 3× scale (48×48 display).
- Sprites are generated procedurally — no PNG/SVG files are stored on disk.
